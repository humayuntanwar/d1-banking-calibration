# BANKING77 test set

`banking77_test.csv` is the 3,080-example test split of [BANKING77](https://huggingface.co/datasets/PolyAI/banking77) (Casanueva et al., 2020): 40 customer queries for each of 77 fine-grained banking intents.

Columns: `text`, `category`.

The copy here is the same file used for this experiment so the run is bit-for-bit reproducible without a Hub download of the dataset.
